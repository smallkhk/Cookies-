Manual Transfer

Transfer via USB or shared folder

Use when the PCs aren't on the same network. Copy a JSON file between machines.

Step 1
Source PC — Export
Creates cookies_export.json
1
Close all browser windows
Chrome, Edge, Firefox must all be closed.
2
Run export_cookies.py
Decrypts and exports all cookie data to a portable file.
python export_cookies.py
3
Copy cookies_export.json
Move the file to PC 2 via USB drive, shared folder, or any file transfer method.

4
Open your browsers
Backed up original files are saved as Cookies.bak — restore them if anything goes wrong.

Reference

How it works

CookieSync decrypts cookies on the source machine and re-encrypts them with a new key on the target.

Browser Storage format Export method Import method
Chrome Encrypted SQLite DPAPI + AES-256-GCM Decrypt with machine key via win32crypt Generate new key on target, re-encrypt all values
Edge Encrypted SQLite DPAPI + AES-256-GCM Same as Chrome Same as Chrome
Firefox Plain SQLite cookies.sqlite Direct read — no encryption layer Direct write into Firefox profile
Things to know
— Session cookies (no expiry date) may not survive — browsers often don't flush those to disk.
— Some sites (Google, banks) bind sessions to IP or device fingerprint and may log you out regardless of the cookie transfer.
— LAN only: the receiver rejects connections from non-private IP ranges. This tool is designed for your local network, not the internet.
— Backups: originals are saved as Cookies.bak (Chrome/Edge) and cookies.sqlite.bak (Firefox) before any overwrite.
— Run as your normal user account, not as Administrator.
— Requirements: Python 3.8+ on both PCs. Install once: pip install pycryptodome pywin32
